# FALCON

## Name
 FALCON (Functional Active Learning with Constraints based on Criticisms and Neighborhood prototypes)

## Description
FALCON, a novel active constraint based clustering method. FALCON identifies homogeneous regions within the dataset by computing prototypes' neighborhoods that minimize the distance between prototypes' distribution and the overall dataset distribution. This ensures that constraint queries are made in the most homogeneous areas possible. Simultaneously, FALCON determine less homogeneous regions by computing criticism neighborhoods, where prototypes fail to adequately represent the data. These critical regions are refined throughout the clustering, further enhancing the clustering quality
